# Компьютерный слух — портал

SPA-портал для проекта акустического восприятия беспилотных автомобилей.
Оформление «Сцена»: 3D-модель Volkswagen Golf VII едет позади всех страниц,
содержимое лежит поверх на полупрозрачных панелях. Тёплый чёрный фон `#0D0D0C`,
приглушённый бирюзовый акцент `#7FC7BD`, прямые углы без скруглений,
шрифты Golos Text / JetBrains Mono.

## Стек

- Vite + React 19 + TypeScript
- React Router (реальные URL для вкладок и параметров состояния)
- CSS Modules + дизайн-токены (`src/styles/tokens.css`)
- three.js r187 для 3D-сцены, без React Three Fiber

## Запуск

```bash
npm install
npm run dev      # http://localhost:4173
npm run build    # tsc + vite build
npm run preview  # предпросмотр production-сборки
npm test         # vitest
```

## Развёртывание

Портал — только статические файлы, их раздаёт один Caddy. Всё нужное для
этого лежит в `deployments/`, так же как в `audio-inference-service`:

```
deployments/
  docker-compose.yaml            # сервис portal_caddy в сети computer-hearing
  dockerfiles/Caddy.Dockerfile   # node собирает портал -> caddy раздаёт dist/
  caddy/Caddyfile                # раздача сайта, кеширование, маршруты SPA
```

```bash
cd deployments
docker compose up -d --build
```

- **Сборка** двухступенчатая: в образе `node` выполняются `npm ci` и
  `npm run build`, в итоговый образ `caddy` попадают только `dist/` и
  `Caddyfile`.
- **Маршруты.** `/inference`, `/models?project=...` и т.п. существуют только
  внутри React Router, поэтому на любой такой адрес Caddy отдаёт `index.html`.
  Исключение — `/assets/*`: несуществующий файл там — честная ошибка 404.
- **Кеширование.** Файлы из `/assets/*` с хешем в имени кешируются «навсегда»;
  `index.html` и остальное — `no-cache`: браузер каждый раз сверяется с
  сервером и сразу получает новую версию после выкладки.
- **Переменные `VITE_*` вшиваются при сборке**, поэтому передаются как
  аргументы сборки (`build.args` в `docker-compose.yaml`), а не при запуске
  контейнера. После их изменения образ нужно пересобрать.
- Внешний шлюз направляет `www.kuronami.fun` на контейнер `portal_caddy:80`
  в сети `computer-hearing`.

## Маршруты

| URL | Экран |
| --- | --- |
| `/` | Главная: описание проекта, подпроекты, команды |
| `/tools` | Инструменты (MLflow, Grafana, Portainer) |
| `/inference` | Инференс: модуль сервиса audio-inference-service |
| `/info?project=road` | Карта моделей и датасеты |
| `/models?project=siren` | Каталог моделей |
| `/models?project=siren&model=siren-emergencynet` | Раскрытая карточка модели |
| `/?open=traffic` | Модалка подпроекта |

Параметры `project`, `model` и `open` являются источником состояния:
ссылки можно шарить, кнопка «назад» работает.

## Структура

Правило простое: всё, что относится к одной странице, лежит в её папке.
Отдельный файл заводится, только если компонент большой или нужен на
нескольких страницах. Стили — один CSS-модуль на страницу.

```
src/
  main.tsx
  app/
    App.tsx            # маршруты и общая разметка: сцена, меню, страница
    Header.tsx         # меню «Разделы»
    app.module.css
  stage/               # 3D-сцена позади всех страниц (грузится отдельным чанком)
    Stage.tsx          # React-обёртка: холст, ракурс по адресу, затемнение
    scene.ts           # three.js: модель, свет, колёса, цикл отрисовки
    camera.ts          # камера: перетаскивание, инерция, перелёт к ракурсу
    road.ts            # бесконечная дорога (бегущие текстуры)
    views.ts           # ракурс камеры для каждого раздела
    stage.module.css
  pages/
    home/              # главная: Hero, Teams, ProjectModal, home.module.css
    info/              # «Информация»: InfoPage, DatasetCard
    models/            # «Модели»: ModelsPage (+ блок про API), ModelCard
    tools/             # «Инструменты»
    inference/         # «Инференс»: загрузка модуля audio-inference-service
    NotFoundPage.tsx
  ui/                  # общее для нескольких страниц
    ui.tsx             # Button, IconButton, Pill, Chip, Spinner, SectionHeader, StatGrid, cn
    Modal.tsx  icons.tsx  ModelScatter.tsx
  data/
    portal.json        # golden-данные
    portal.ts          # типы, доступ к данным и выборки
  lib/                 # format, scatter, hooks — чистые функции и хуки
  styles/              # tokens.css (дизайн-токены), global.css
public/
  models/golf7.glb     # 3D-модель Volkswagen Golf 7 mk7
  favicon.svg
```

Данные вынесены в единый golden-файл `data/portal.json`: модели вложены
в проекты, у каждой модели есть стабильный `id` и блок `weights` (ссылки
пока `null`). Типы, доступ к данным и выборки — в `data/portal.ts`.
Расчёты — в чистых функциях (`lib/scatter.ts`, `lib/format.ts`), поэтому
их можно тестировать без DOM. Тесты лежат рядом с кодом (`*.test.ts`):
форматирование, golden-данные, ID моделей, парето-фронт и блок команд.

## Инференс

Раздел `/inference` — отдельный сервис (репозиторий `audio-inference-service`,
папка `frontend`). Он собирается в один файл `inference.js`, который раздаёт
свой Caddy, и портал загружает его во время работы
(`pages/inference/InferencePage.tsx`): обновление инференса не
требует пересборки портала. Интерфейс инференса рисуется внутри Shadow DOM,
стили портала и инференса друг на друга не влияют; дизайн-токены портала
(CSS-переменные) инференс использует.

Адрес модуля можно переопределить, например для локальной проверки:

```bash
VITE_INFERENCE_URL=http://localhost:8080/inference.js npm run dev
```

По умолчанию — `https://inference.kuronami.fun/inference.js`.

## Оформление и 3D-сцена

- **Сцена одна на весь портал.** `Stage` подключён в общей разметке
  (`app/App.tsx`) и не пересоздаётся при переходах между разделами: холст
  закреплён на весь экран позади содержимого (`position: fixed`).
  three.js грузится отдельным чанком и не попадает в начальный бандл.
- **Движение.** Автомобиль стоит в начале координат, а «едет» окружение:
  текстуры дороги сдвигаются навстречу (`road.ts`), колёса вращаются со
  скоростью, соответствующей пройденному пути (`scene.ts`). Края дороги
  растворяются в тумане цвета фона.
- **Камера** (`camera.ts`). Автомобиль можно крутить мышью или пальцем,
  после отпускания остаётся инерция; без действий камера медленно облетает
  машину. Колесо мыши и вертикальный жест не перехватываются — страница
  прокручивается как обычно.
- **Ракурсы** (`views.ts`). У каждого раздела свой ракурс и положение
  автомобиля на экране; при переходе камера плавно перелетает к нему.
  Чтобы поменять вид раздела, достаточно поправить числа в этом файле.
- **Затемнение.** На главной сцена яркая; на остальных страницах и при
  прокрутке главной вниз она приглушается, чтобы не спорить с текстом.
- **Клики.** Пустые места страницы пропускают мышь к сцене
  (`pointer-events: none` у `main`), а сами блоки её ловят — поэтому
  автомобиль можно крутить в свободных областях на любой странице.
- **Панели.** Блоки с текстом — полупрозрачные (`--panel`, `--surface-*`)
  с размытием фона. Все `--radius-*` равны нулю: скруглений нет.
  Цвета и размеры заданы в `styles/tokens.css`.
- Навигация открывается кнопкой «Разделы» справа сверху: панель выезжает
  с правого края, закрывается по Escape, клику на фон и кнопке; фокус
  остаётся внутри меню. Верхней шапки и подвала нет.
- У направлений собственные акценты и линейные иконки: голубой трафик,
  зелёное покрытие, коралловые сирены, янтарная диагностика.
- Фотографии команд подключены из `images/*.png` и загружаются лениво.
- При `prefers-reduced-motion` езда, авто-вращение и плавные перелёты
  отключаются (крутить автомобиль по-прежнему можно); отрисовка
  приостанавливается, когда вкладка скрыта.

## 3D-модель

`public/models/golf7.glb` весит ~10 МБ и теперь нужна на каждой странице
(браузер скачивает её один раз и берёт из кеша). При необходимости её можно
дополнительно сжать через `gltf-transform`.

Сцена опирается на имена узлов модели: оси колёс `WHEEL_LF`, `WHEEL_RF`,
`WHEEL_LR`, `WHEEL_RR` (внутри — тормоз `BRAKE_*`, он не вращается).
При замене модели эти имена нужно сохранить или поправить в `stage/scene.ts`.

Модель — [Volkswagen Golf 7 mk7](https://sketchfab.com/3d-models/volkswagen-golf-7-mk7-3c86d324d56f4027b08cbd7ba5f10bbb)
автора DR1KING100K, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Лицензия требует указывать автора: подпись выводится на первом экране главной
(`pages/home/Hero.tsx`). При замене модели подпись нужно обновить.

# Компьютерный слух — портал

SPA-портал для проекта акустического восприятия беспилотных автомобилей.
Чисто чёрный фон, бирюзовый акцент `#64CBBF`,
шрифты Golos Text / JetBrains Mono, 3D-модель Volkswagen Golf VII.

## Стек

- Vite + React 19 + TypeScript
- React Router (реальные URL для вкладок и параметров состояния)
- CSS Modules + дизайн-токены (`src/shared/styles/tokens.css`)
- three.js r187 для 3D-сцены, без React Three Fiber

## Запуск

```bash
npm install
npm run dev      # http://localhost:4173
npm run build    # tsc + vite build
npm run preview  # предпросмотр production-сборки
npm test         # vitest
```

## Маршруты

| URL | Экран |
| --- | --- |
| `/` | Главная: hero, подпроекты, 3D-модель |
| `/tools` | Инструменты (MLflow, Grafana, Portainer) |
| `/info?project=road` | Карта моделей и датасеты |
| `/models?project=siren` | Каталог моделей |
| `/models?project=siren&model=siren-emergencynet` | Раскрытая карточка модели |
| `/?open=traffic` | Модалка подпроекта |

Параметры `project`, `model` и `open` являются источником состояния:
ссылки можно шарить, кнопка «назад» работает. Вкладка «Инференс» оставлена
заглушкой в навигации, без бейджа.

## Структура

```
src/
  app/                 # роутер, shell, общие стили приложения
  pages/               # Home, Tools, Info, Models, NotFound
  widgets/             # header/footer, hero, 3D-viewer, scatter, grids, modal
  entities/            # типы и селекторы project/model/dataset/portal
  shared/              # UI-примитивы, хуки, утилиты, токены, portal.json
  test/                # настройка vitest
public/
  models/golf7.glb     # 3D-модель Volkswagen Golf VII
  favicon.svg
```

Данные вынесены в единый golden-файл `shared/data/portal.json`: модели
вложены в проекты, у каждой модели есть стабильный `id` и блок `weights`
(ссылки пока `null`). Доступ к данным идёт через `shared/data/portal.ts`.
Расчёты — в чистых функциях (`shared/lib/scatter.ts`,
`entities/model/selectors.ts`), поэтому их можно тестировать без DOM.
В `src/shared/*.test.ts` покрыты форматирование, golden-данные, ID моделей
и парето-фронт.

## 3D-сцена

- Модель загружается лениво вместе с чанком `CarViewer`, чтобы three.js не
  попадал в начальный бандл.
- Навигация на всех экранах открывается кнопкой «Разделы» справа сверху:
  модальная панель выезжает с правого края. Доступны закрытие по Escape,
  клику на фон и кнопке; фокус остаётся внутри меню. Верхней шапки нет.
- Главная: фотобаннер `images/machine_hearing_main_photo.PNG`, ниже — описание
  проекта слева и 3D-платформа справа. Четыре подпроекта расположены отдельным
  рядом внизу. На десктопе композиция подстраивается под первый экран;
  на телефонах блоки идут вертикально, карточки — сеткой 2×2.
  Ниже расположен раздел четырёх команд: ML, алгоритмы локализации, датасет
  и установка. Команды отделены от поднаправлений распознавания.
- Фотографии команд подключены из `images/*.png`, загружаются лениво.
  Секции команд чередуют изображение слева и справа, разделены тонкими линиями
  с цветовыми акцентами. На телефонах текст и фото идут вертикально.
  Для ML фотография не используется; график локализации показан без обрезки.
  Исходные JPG сохранены рядом с PNG-копиями.
- У направлений собственные акценты и линейные иконки: голубой трафик,
  зелёное покрытие, коралловые сирены, янтарная диагностика. У карточек
  однотонный фон без градиентов. Цвета заданы в дизайн-токенах.
- В сцене сохранены polar grid, тени и пульсирующие кольца. Цветные
  чертёжные выноски связывают подписи с автомобилем и подсвечивают карточки;
  нажатие на метку или карточку открывает подпроект.
- При `prefers-reduced-motion` авто-вращение отключается; рендер
  приостанавливается, когда вьюер вне вьюпорта или вкладка скрыта.
- Метки доступны с клавиатуры и остаются видимыми на мобильных.

## Заглушки

Ссылки Kaggle / Google Drive, кнопки скачивания `.pt` / `.onnx` и адреса
инструментов — заглушки. Для API можно задать хост:

```bash
VITE_API_HOST=https://api.example.com npm run dev
```

Если переменная не задана, в примерах API показывается `[API_HOST]`.

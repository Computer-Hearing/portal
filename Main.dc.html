Модели можно скачивать через API

Список моделей подпроекта, веса PyTorch и ONNX доступны по HTTP — удобно для CI и для обновления моделей на борту. Хост и токен — заглушки.

# Список моделей подпроекта (traffic | road | siren | diag)
GET  https://[API_HOST]/api/v1/models?project=road

# Скачать веса или ONNX по ID модели
GET  https://[API_HOST]/api/v1/models/{model_id}/weights   → .pt
GET  https://[API_HOST]/api/v1/models/{model_id}/onnx      → .onnx
